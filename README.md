# ImmoSecureNet.cd

Dépôt principal public d'**ImmoSecureNet**.

ImmoSecureNet est une plateforme Web responsive orientée immobilier, marché de l'habitat, expériences et services de confiance.

## Développement actuel

Le flux de travail de référence est :

**Google AI Studio → GitHub → Codex → stabilisation Web/mobile responsive → publication Web → Android plus tard.**

## Fonctionnalités actuellement présentes dans le dépôt

- React / TypeScript / Vite.
- Firebase Authentication.
- Cloud Firestore.
- Firebase Storage.
- Gestion des utilisateurs et rôles.
- Biens immobiliers.
- Publication.
- Messagerie.
- Journal immobilier et économique.
- Administration et profils spécialisés déjà présents dans le code.

## Documentation

- `docs/ARCHITECTURE.md` : architecture générale prévue à long terme.
- `docs/INTERFACE_CLIENT.md` : spécification actuelle de l'accueil, de la navigation et du Journal.
